## Averaging

For more than two classes, the `average` parameter is required for precision, recall, and F1. `macro` treats every class equally, `weighted` weights by support, and `micro` pools counts across classes. These can rank models differently, so the averaging method is stored with every result.

## Choosing metrics

Accuracy is easy to read but misleading under class imbalance. Balanced accuracy, MCC, and PR AUC are more informative when classes are imbalanced. ROC AUC measures ranking, not calibration; use the [calibration](/docs/calibration) guide to assess probabilities.
