# Classification

Binary, multiclass and multilabel classification, with sample weights throughout.

## Usage

<CodeBlock lang="python" status="implemented" statusLabel="v0.1.0" code={`
import evalsuite as es

es.accuracy(y_true, y_pred)
es.f1(y_true, y_pred, average="macro", zero_division="warn")
es.roc_auc(y_true, y_prob)

cm = es.confusion_matrix(y_true, y_pred, labels=[0, 1, 2])

report = es.classification_report(y_true, y_pred)   # precision, recall, F1, specificity, support
print(report.summary())
`} />

## Averaging

For more than two classes, `average` controls how per-class values are combined. `macro` treats every class equally, `weighted` weights by support, `micro` pools counts across classes, `samples` averages per observation for multilabel data, and `None` returns per-class values. The default `"auto"` resolves to `binary` for binary targets and `macro` otherwise; the resolved value is stored in `result.params["average"]`.

## Choosing metrics

Accuracy is easy to read but misleading under class imbalance. Balanced accuracy, MCC and PR AUC are more informative when classes are imbalanced. ROC AUC measures ranking, not calibration; use the [calibration](/docs/calibration) guide to assess probabilities.
