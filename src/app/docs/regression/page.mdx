## Domain restrictions

Some metrics are only defined on part of the real line. Inputs are checked before computation:

- **MAPE** requires every target to be non-zero.
- **MSLE** and **RMSLE** require targets and predictions greater than −1.
- **R²** is undefined for constant targets.

Invalid inputs raise `MetricInputError` instead of producing infinities or misleading values.
