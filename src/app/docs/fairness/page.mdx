# Fairness

<CodeBlock lang="python" status="implemented" statusLabel="v1.2.0" code={`

For every group (and every intersection of attributes, such as `sex=F & age=65+`): selection rate, true and false
positive rates, positive predictive value and accuracy with Wilson intervals, ROC AUC (DeLong) and
calibration-in-the-large. Then the gap measures with bootstrap intervals that resample within each group:
demographic parity difference and ratio, equalized odds, equal opportunity and predictive parity differences,
and Fisher tests of every group against the reference group, Holm-adjusted. Gap values are identical to Fairlearn's.
Groups below `min_group_size` are listed but not tested.
