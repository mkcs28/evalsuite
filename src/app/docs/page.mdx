# Documentation

EvalSuite is a Python package that brings machine learning, clinical, statistical, segmentation, and object-detection evaluation into one consistent framework. These docs describe **evalsuite-python v0.3.0**, installed with `pip install evalsuite-python`.

<Callout title="What is available now">
  Every module on the roadmap is released: classification, regression, clinical evaluation, calibration, model comparison, confidence intervals, hypothesis tests, segmentation, object detection, plots, reports and the command-line tool.
</Callout>

## Where to start

- [Getting started](/docs/getting-started) explains installation and the two API levels.
- [Core concepts](/docs/concepts) covers validation, the evaluation context, results, and conventions.
- [Metric reference](/docs/metrics) lists every metric with its formula, assumptions, and references, and whether it is implemented.

## How these docs are maintained

Every code example marked with a version was run against the released package before publishing. The package keeps its own metric registry (`es.list_metrics()`, `es.metric_info(...)`), and the metric reference marks exactly the metrics that registry provides as implemented.
