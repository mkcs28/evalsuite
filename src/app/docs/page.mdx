# Documentation

EvalSuite is a planned Python package that brings machine learning, clinical, statistical, segmentation, and object-detection evaluation into one consistent framework.

<Callout tone="warning" title="Pre-release documentation">
  No version of EvalSuite has been published yet. These pages describe the **planned** design and API so that it can be reviewed before implementation. Every code example is marked as a planned API and will not run until the corresponding release ships.
</Callout>

## Where to start

- [Getting started](/docs/getting-started) explains installation and the two API levels.
- [Core concepts](/docs/concepts) covers validation, the evaluation context, results, and conventions.
- [Metric reference](/docs/metrics) lists every planned metric with its formula, assumptions, and references.

## How these docs are maintained

Metric pages are generated from a structured metric registry rather than written by hand. Once the Python package exists, its own registry (`es.list_metrics()`) will be exported to JSON and validated by this site, so the documentation cannot drift from the implementation.
