# Report cards (TRIPOD+AI and model cards)

<StatusBadge status="implemented" label="Available in v1.0.0" />

`report_card` computes what a reporting standard asks for and writes it up: for TRIPOD+AI (Collins et al., BMJ 2024), the evaluation sample and outcome events, discrimination (c-statistic with a DeLong interval), calibration-in-the-large and calibration slope (bootstrap intervals), the Brier score, sensitivity / specificity / PPV / NPV at a risk threshold (Wilson intervals), net benefit against treat-all and treat-none, and performance by subgroup. It also lists which checklist items are covered and which need your own text (missing data, outcome definition).

<CodeBlock lang="python" status="implemented" statusLabel="v1.0.0" code={`
import evalsuite as es

card = es.report_card(y_true, y_prob, threshold=0.2, groups=site, group_name="site")
print(card.paragraph())       # a results paragraph with intervals
card.to_markdown()            # paragraph, table, subgroup table, checklist
card.to_latex(caption="Model performance", label="tab:performance")
card.to_docx("performance.docx")   # pip install "evalsuite-python[docx]"

model_card = es.report_card(
    y_true, y_prob, standard="model-card",
    context={"intended_use": "Triage support in emergency departments.", "caveats": "Not validated in children."},
)
`} />

With `standard="model-card"`, the sections of a model card (Mitchell et al., 2019) are produced, with the quantitative analyses filled in and the narrative sections taken from `context`.
