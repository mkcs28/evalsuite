# JavaScript, C, R and Julia

<StatusBadge status="implemented" label="Available in v1.0.0" />

Every binding calls the same Rust engine through one JSON entry point, so a metric gives the same value in every language. Available metrics: accuracy, balanced accuracy, precision, recall, F1, specificity, MCC, ROC AUC, average precision, log loss, Brier score, MAE, MSE, RMSE, R², MAPE, median absolute error, max error, BLEU, chrF, TER, ROUGE-1/2/L, PSI and the Kolmogorov–Smirnov drift test. Arguments: `y_true`, `y_pred`, `y_prob`, `average`, `sample_weight`; `references` / `predictions` for text; `reference` / `current` for drift.

## JavaScript and the browser (npm, WebAssembly)

<CodeBlock lang="javascript" status="implemented" statusLabel="v1.0.0" code={`
// npm install evalsuite
const es = require("evalsuite");
es.evaluate("f1", { y_true: [0, 1, 1, 0], y_pred: [0, 1, 0, 0] });
// { metric: "f1", value: 0.6666666666666666 }

// In the browser or a bundler
import init, { evaluate } from "evalsuite/web";
await init();
evaluate("bleu", { references: ["the cat sat on the mat"], predictions: ["the cat sat on a mat"] });
`} />

Nothing leaves the page: the engine runs in WebAssembly. Try it in the [playground](/playground).

## C

<CodeBlock lang="c" status="implemented" statusLabel="v1.0.0" code={`
#include "evalsuite.h"   /* link with -levalsuite_c */

char *r = evalsuite_call("roc_auc", "{\\"y_true\\":[0,0,1,1],\\"y_prob\\":[0.1,0.4,0.35,0.8]}");
if (r == NULL) fprintf(stderr, "%s\\n", evalsuite_last_error());
else { puts(r); evalsuite_free(r); }   /* {"metric":"roc_auc","value":0.75} */
`} />

Build the shared and static library with `cargo build --release -p evalsuite-capi` (from the `rust/` directory of the repository); the header is `rust/evalsuite-capi/include/evalsuite.h`.
