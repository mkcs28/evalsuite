evalsuite evaluate \\

## Behaviour

- `--help` is available on every command.
- Exit code 0 means success; non-zero codes distinguish validation errors from internal errors.
- Output paths must be given explicitly. Existing files are not overwritten unless `--overwrite` is passed.
- Input files are parsed as CSV only. The CLI never executes shell commands or user-supplied code.
