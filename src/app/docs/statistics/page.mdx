# Statistical analysis

<StatusBadge status="in-development" label="Paired tests, effect sizes and corrections in v0.1.0; more tests in v0.2.0" />

Statistical tests in EvalSuite return a structured result containing the statistic, p-value, degrees of freedom where applicable, an effect size, and the method used. They never return a bare p-value.

<Callout title="What a p-value does not tell you">
  A p-value measures how compatible the data are with a null hypothesis under the test's assumptions. It does not measure the size or practical importance of an effect and does not establish causation. EvalSuite reports effect sizes and intervals next to every test for this reason.
</Callout>

## Usage

<CodeBlock lang="python" status="implemented" statusLabel="v0.1.0" code={`
import evalsuite as es

res = es.mcnemar_test(y_true, pred_a, pred_b)
res.statistic, res.p_value

es.delong_test(y_true, prob_a, prob_b)
es.paired_bootstrap_test("f1", y_true, pred_a, pred_b, random_state=0)

es.cohens_d(scores_a, scores_b, paired=True)
es.cliffs_delta(scores_a, scores_b)
es.adjust_pvalues(p_values, method="holm")   # bonferroni, holm, bh, by
`} />

## Planned tests (v0.2.0)

| Family | Tests |
| --- | --- |
| Parametric | independent t-test, paired t-test, one-way ANOVA, repeated-measures ANOVA |
| Non-parametric | Mann–Whitney U, Wilcoxon signed-rank, Kruskal–Wallis, Friedman |
| Categorical | chi-square, Fisher's exact, McNemar |
| Assumptions | Shapiro–Wilk, Kolmogorov–Smirnov, Anderson–Darling, Levene, Bartlett |
