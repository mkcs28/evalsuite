# Bootstrap and confidence intervals

<StatusBadge status="implemented" label="Available in v0.1.0" />

A metric estimated on a finite test set is uncertain. EvalSuite attaches an interval to estimates using either an analytical method suited to the parameter or a reproducible bootstrap.

## Analytical intervals

For proportions such as accuracy, sensitivity, or specificity, the Wilson score interval is the default because it keeps good coverage for small samples and proportions near 0 or 1. Clopper–Pearson is available when guaranteed (conservative) coverage is preferred.

<CodeBlock lang="python" status="implemented" statusLabel="v0.1.0" code={`
import evalsuite as es

es.accuracy_ci(y_true, y_pred, method="wilson", level=0.95)
es.proportion_ci(8, 10, method="clopper-pearson")
es.roc_auc_ci(y_true, y_prob)          # DeLong
`} />

## Bootstrap engine

<CodeBlock lang="python" status="implemented" statusLabel="v0.1.0" code={`
ci = es.bootstrap_ci(
    "f1", y_true, y_pred,
    n_resamples=2000,
    level=0.95,
    method="bca",          # or "percentile", "basic"
    random_state=42,
)
ci.estimate, ci.low, ci.high
`} />

The engine is deterministic for a fixed `random_state`, and never touches global random state. Resampling is stratified by class for classification metrics.
